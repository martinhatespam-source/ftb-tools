Privacy policy

For the Bucks tools, last updated 12 November 2026.

Who uses it

For the Bucks tools is a private desktop tool. Only the owner of the YouTube channel For the Bucks uses it, to manage that one channel. It has no other users and no public sign-up.

What it uses

With the owner's permission, the tool uses the YouTube API Services. It reads the channel's own details, video list and view counts. It uploads and edits the channel's own videos, thumbnails, subtitles, playlists and comments. It does not read, collect or store data about viewers or any other person.

Where data is kept

The sign-in key is kept only on the owner's own computer, in its user settings. Nothing is sent to any server other than Google's, and nothing is sold or shared.

Google and YouTube

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Stopping access

Access can be removed at any time at myaccount.google.com/permissions. Removing it also stops the tool.
